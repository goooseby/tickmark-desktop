# Tickmark 系统规则

Tickmark 记录应用、页面和文档的实际使用区间。报告从记录回答「用了什么、用了多久、发生在哪个时间段」。用户自行解释记录及其用途。

| 规则 | 维护位置 | 当前状态 |
| --- | --- | --- |
| CAP · Windows 计时、锁屏、空闲、视频/放映豁免、页面识别 | [Windows 使用计时规则](windows-usage-capture.md) | Windows 与 Edge 已接入，具体覆盖见运行文档 |
| DATA · 设备身份、区间契约、数据镜像 | [设备与统计报表规则](reports.md#data-设备和区间) | 本机 SQLite 与本地设备快照可读 |
| AN · 聚合、覆盖率、日期、并发、版本修订 | [设备与统计报表规则](reports.md#an-统计口径) | 日报与周月基本分析可用 |
| HUB · 多设备仪表盘 | [首页布局与统计规则](multi-device-dashboard.md) | 首屏时间轴、设备饼图、跨设备应用榜；时间轴平滑短切换并折叠无活动区间 |
| UX · 页面、交互、数据核对、验收 | [界面结构与导航](interface.md) · [报表设计](reports.md#ux-报表界面) · [界面验收](dashboard-review.md) | 页面职责、共享范围与时间轴展示规则已同步 |
| SYNC · 邮箱账号、设备鉴权、修订、删除和下行 | [跨端同步规则](sync.md) | 服务端与生产邮件已部署，Android 上行、Windows 收发已实现，真机后台行为待验证 |
| OPS · 桌面进程、托盘、环境与本机集成 | [运行与维护](rust-desktop.md) | 本机可运行 |

修改规则时先更新其所属文档，并在下表记录变更范围和核对方法。临时验证材料放在忽略提交的 `artifacts/`。遇到平台限制时在对应规则中注明现行行为。
