# 多设备仪表盘

## 首页布局

1. **核心数字**。当天跨设备去重用时为主数字，旁边显示同时使用和设备累计；仅选一台设备时显示该设备用时与记录覆盖。统计范围固定为所选自然日。
2. **使用时间轴**。全宽、首屏主图。各设备共用当地时间刻度；多设备时增加「同时使用」轨道。悬停只显示虚线游标和「此刻」应用；拖动框选或点击色块进入聚焦，整轴放大到所选范围并换成更细的自适应刻度，轴下方固定展示「已选时段 · 应用排行」。Esc 返回全天。色块按应用着色，设备身份由左侧圆点和泳道名表示。
   - **短切换平滑**。同一设备、同一应用相邻区间间隔不超过 2 秒时合并显示；夹在同一应用之间、持续不超过 2 秒的未识别间隙或短暂切换也并入该应用。平滑只影响时间轴，记录明细与统计仍使用原始区间，色块提示会注明合并段数。
   - **长时间无活动折叠**。当天最长的最多 4 段无活动区间（至少 20 分钟）压缩显示，包括睡眠/离线、无记录和未来；每段默认限制为正常活动区长度的 5%，最短按 5 分钟计。折叠段在轴上给出「睡眠 / 未来 + 时长」标签；较短或相邻的折叠段只显示名称，完整时长在悬停中查看。悬停还会显示真实起止，点击可聚焦该段。聚焦模式使用均匀时间轴，便于核对。
3. **设备用时分布与跨设备应用榜**。宽窗口并排，窄窗口顺序堆叠。设备分布使用实心饼图，按实际设备动态分片，图例给出名称、时长、占比；悬停扇区或图例浮出该设备的应用排行，可滚动查看全部，鼠标移入浮窗不会消失，并可直接「只看这台设备」。应用榜固定 5 行高度，超出时在榜内滚动，底部标出总数。每行标明设备来源。
4. **本周上下文**。时间轴上方保留一行本周去重用时和同时使用摘要，点击「查看趋势」进入周月分析，不在首页重复完整周图。
5. **数据来源与覆盖**。折叠呈现每台设备的来源与当天观测情况，保留单设备记录明细和设备管理入口。

## 统计与异常状态

- 总屏幕使用时间取各设备活跃区间并集。设备累计为各设备活跃时长之和，饼图以此为分母。同时使用取至少两台设备活跃的区间并集，三台并行的同一分钟只贡献一次。
- 整段缺记录用 `—`，确有观测且无活跃显示零。时间轴分别标示应用、已观测未活跃、采集缺口、无记录与未来。部分覆盖时，摘要注明按已有记录计算。应用榜使用应用前台口径，允许并行应用分别计时。
- 使用桌面显示时区切日和自然周，本周从周一开始。今天和本周只计算到当前时刻。
- 今日复盘承载应用、站点和文档明细；趋势页保留周月趋势与比对；记录明细用于核对起止时间，从时间轴选区、今日复盘或设置进入。

验收使用单设备、同类多设备、三台并发、缺报和跨午夜样例，检查图表与明细的选区一致性，以及宽窄窗口和深色显示。详细口径见 [设备与统计报表规则](reports.md#an-统计口径)。
