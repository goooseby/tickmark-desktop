# 界面结构与导航

## 页面职责

| 页面 | 入口 | 时间范围 | 主要职责 |
| --- | --- | --- | --- |
| 多设备仪表盘 | 主导航第一项，默认打开 | 当天 | 跨设备核心数字、共用时间轴、设备用时饼图、跨设备应用榜、本周上下文和数据来源。 |
| 今日复盘 | 主导航第二项 | 当天 | 分时摘要、应用用时与站点/文档明细，适合回看一天的内容。 |
| 趋势 | 主导航第三项 | 周或月 | 每日趋势、小时分布、应用/文档/站点排行、设备覆盖与并发分析。 |
| 记录明细 | 时间轴选区、今日复盘时段、设置「数据与质量」 | 指定日期或选区 | 核对原始区间、设备状态和页面；默认应用会话，可切换设备记录。 |
| 设置 | 左下角齿轮 | 全局 | 本机采集、浏览器扩展、账号同步、数据库、其他设备、数据质量和文档标题。 |

「记录明细」不是一级导航。它从正在查看的内容进入，并通过返回按钮回到原来的页面、日期、设备筛选和选区。

## 共享范围

- 日期和设备筛选在仪表盘、今日复盘、趋势之间共享，切换页面时保持。
- 仪表盘固定为当天；趋势负责周/月；今日复盘固定为当天。
- 记录明细从来源继承日期、设备和选区；从设置进入时默认当天、全部设备。
- 页面不支持当前范围时会收窄并明确提示，不静默切换成另一套数据。

## 时间轴展示规则

- 同一设备、同一应用相邻区间间隔不超过 2 秒时合并显示。
- 夹在同一应用之间、持续不超过 2 秒的未识别间隙或短暂切换并入该应用。
- 平滑只影响时间轴；记录明细、汇总和导出仍使用原始区间。色块提示会注明合并段数。
- 当天最长的最多 4 段无活动区间（至少 20 分钟）压缩显示，包括睡眠/离线、无记录和未来。
- 每段最多占正常活动区长度的 5%，最短按 5 分钟计；轴上显示名称和时长，较短或相邻的折叠段可能只显示名称，完整时长在悬停中查看。
- 折叠段支持悬停查看真实起止和点击聚焦；聚焦模式使用均匀时间轴，避免在核对时再次压缩。
- 参数集中在 `native/web/view.mjs` 的 `TIMELINE_SMOOTH_GAP_MS` 与 `TIMELINE_SCALE`，调整后需重新验证真实样本、窄窗和深色模式。

## 命名约定

- 核心页面始终叫「多设备仪表盘」，不使用「概览」作为替代名称。
- 原来的「跨端汇总」改为「趋势」，避免与仪表盘的跨设备总览混淆。
- 原来的「时段流水」改为「记录明细」，不再作为一级导航名称。
- 界面文案优先使用用户能理解的动作和对象，内部术语留在文档和诊断信息中。
